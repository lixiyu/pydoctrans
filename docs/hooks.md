# 回调钩子

pydoctrans 提供转换前（before）和转换后（after）两个钩子注入点。

## 概念

```
before hooks → LO 转换 → after hooks
     ↑                          ↑
  修改源数据                 修改输出/副作用
  修改文件名                 写入 meta
  可中止转换                 记录日志
```

## Before Hook

转换前执行。可以修改源数据和文件名，抛出异常可中止转换。

```python
from pydoctrans import ConversionContext, convert

def validate_size(ctx: ConversionContext) -> None:
    if len(ctx.data) > 10 * 1024 * 1024:
        raise ValueError("文件超过 10MB")

def sanitize_name(ctx: ConversionContext) -> None:
    ctx.file_name = ctx.file_name.replace(" ", "_")

pdf = convert(docx, format="pdf", file_name="my doc.docx",
              before=[validate_size, sanitize_name])
```

## After Hook

转换后执行。可以修改输出数据（如水印注入）、写入 meta（如上传 URL）。

```python
def watermark(ctx: ConversionContext) -> None:
    """在 PDF 末尾追加文本标记。"""
    ctx.data = ctx.data + b"\n-- Generated by pydoctrans --"

def upload_to_s3(ctx: ConversionContext) -> None:
    """自动上传到 S3。"""
    key = f"converted/{ctx.meta.get('id', 'unknown')}.{ctx.format}"
    url = s3_client.put_object(key, ctx.data)
    ctx.meta["s3_url"] = url

pdf = convert(
    docx, format="pdf", file_name="report.docx",
    after=[watermark, upload_to_s3],
)
print("上传到:", pdf_ctx.meta.get("s3_url"))
```

## 错误处理

before 钩子抛出异常 → 立即中止，异常向上传播。

after 钩子抛出异常 → 不阻断其他钩子执行，所有错误聚合为 `HookExecutionError`：

```python
try:
    convert(data, format="pdf", file_name="f.docx", after=[hook1, hook2])
except HookExecutionError as e:
    for name, exc in e.errors:
        print(f"    {name}: {exc}")
```

## HTTP API 中的钩子

当前仅 Python API 支持钩子。HTTP API 的钩子支持将在后续版本中通过命名钩子注册机制提供。
